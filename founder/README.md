Order: `idea.md` → `board.md` → `competitors.md` → `panel/` (buyers) → `pricing.md` → `offer.md` → `cfo.md` → `marketing.md` → `brand.md` → `ops.md` → `launch.md` → `business-plan.md` / `one-pager.md`.

Re-run any step: `/founder-board`, `/founder-consumer --quick`, `/founder-cfo`, `/founder-plan`… (each reads this folder). The panel is simulated buyers; the numbers are projections.
